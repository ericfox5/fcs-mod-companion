Start

      
Run uniform-studio.cmd (or node serve.mjs --open) in this folder. It finds your RPCS3 install from the bridge config, opens this page, and connects it to USRDIR\DLC and to qkl_fe2ig.ast. Every save keeps a backup under %LOCALAPPDATA%\ncaa-bridge\uniforms\backup.

      
Editing a team

      
    
        
  1. Pick the team. Its uniforms (Home, Away, alternates) show which helmet, jersey, pants, socks and shoes they use; change any of them with the dropdowns. Teams that still use the game's built-in definition get a Copy to DLC folder button first.
    2. 
        
  2. Under Parts, open a part's textures. Edit DDS writes the texture as a DDS and opens it in your DDS editor (Paint.NET with its DDS plugin). Save it there and the bigfile is repackaged within a second or two; the log confirms it. Import takes a DDS or PNG you already have; Quick edit opens the in-page editor for recolours and touch-ups.
    3. 
        
  3. Parts that live inside the game archive get a Pull into folder button; after that they are editable like any other.
    4. 
        
  4. New set clones another team's pieces into this team's slot (same-length names) and writes the uniform file; Clone part on a team does the same for one piece.
    5. 
      

      
How the files fit together

      
Every team sits on a six-letter asset slot (TEAM.CSAT). At game load the game looks in every FCS_DLC_* folder for SLOT_Pack0_MixAndMatch.XML; without one it uses the definition baked into qkl_fe2ig.ast (entry SLOT_MIXANDMATCH). The XML lists parts, each naming a bigfile and the scene inside it, and says which official uniforms use it; TEAM.TUHO/TUAW are the home and away rows. Bigfiles are found by name in any FCS_DLC_* folder, then in the archive by a hash of the name, then loose in USRDIR; a name that resolves nowhere crashes the game at load.

      
Rules

      
    
        
  • A texture keeps its size, format (DXT1/DXT5) and mip count; the full mip chain is regenerated from your edit. Save DDS files as BC1/DXT1 or BC3/DXT5 (with or without mipmaps) or 32-bit uncompressed; same size as the original.
    • 
        
  • Renames keep lengths: slot 6 characters, year 4 digits, colour token as long as the donor's.
    • 
        
  • Close the game, or sit at its menu, while saving into the game folder. Every league member needs the same DLC files.
